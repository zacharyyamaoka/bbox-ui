The components kit is the atoms that **draw** a scene element: `Block`, `Port`,
`Trace`, `Bar`, `CodeEditor`, and their composites.

**The rule:** props in, DOM out. No state beyond a component's own gesture.
**Imports no canvas engine, and imports no scene.** That second constraint is
the load-bearing edge of the whole architecture — it is what lets the same
`Block` be driven by a story literal, a React Flow node, a tldraw shape or a
server-side render. The [Scene kit](/docs/scene) may know about components'
prop vocabularies through explicit adapters; a component never knows a scene
exists.

Every component is copy-paste: you own the source, there is no runtime
dependency on this project. Anything with a registry item installs with

```bash
npx shadcn@latest add zacharyyamaoka/bbox-ui/<item>
```

## Status map

This is the real inventory, read from the source tree — not a roadmap. The
grouping below is the same one the project's own Storybook uses to review
these components.

Two lineages appear, per [ARCHITECTURE.md](https://github.com/zacharyyamaoka/bbox-ui/blob/main/ARCHITECTURE.md):
**trunk** is `apps/storybook-basics`, where design decisions land now; **v1**
is `packages/bbox-ui`, the original core, frozen and kept stable because this
site's live previews and the oldest registry items render it. A component
listed once in each lineage is the same idea at two ages — the trunk version
is the current design.

Only [Port](/docs/components/port) and [Block](/docs/components/block) have
full documentation pages today, and both document the v1 lineage. Every other
row is built and installable, but its documentation is its story file and its
source.

### Host adapters

The React Flow and tldraw adapters wrap the v1 core. They are in the registry
but **not yet installable** — they import the shared core as a workspace
package rather than as copied files. Use them as reference implementations.

| Item | Status | Registry item |
|---|---|---|
| Block node (React Flow) | Built — reference only, not installable | `block-node-reactflow` |
| Block shape (tldraw) | Built — reference only, not installable | `block-shape-tldraw` |
