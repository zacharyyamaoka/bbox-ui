The real thing behind the card is @joint/shapes-general-tools: a package of small classes that each turn one property of a shape into a point you can grab. Drag the point, the property changes, clamped to what is legal; double-click it, the property resets. “Parametric drag-handle” means exactly that — the handle does not move or resize the shape, it drives one named parameter (a corner radius, a slant, a fold, a divider). All of them subclass one base, Control, whose whole contract is three pure methods; the base owns the pointer lifecycle, the coordinate conversion, the undo batching and the reset gesture. Two corrections to the card now that the source is open on disk: the count is 13, not 14, and the “ready-made donor” reading did not survive contact — figure 113 shows why. What DID survive is better than a donor: this repo already split its one existing handle editor exactly where JointJS split theirs.
