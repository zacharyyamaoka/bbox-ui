JointJS's open-source core is thinner than its reputation. Undo/redo, box selection, snaplines, the halo (floating action toolbar), and the stencil (drag-and-drop palette) are all JointJS+ — a separate commercial package — not the free MPL-2.0 core. Because SystemSketch is built on tldraw, it already gets nearly all of that for free from tldraw's own stock engine — the exact bet this repo's CLAUDE.md "tldraw stays stock" rule already made.

Of 20 features compared: 17 are at parity or ahead, 1 is an already-known, already test-guarded weakness (custom shape authoring's six-registry cost — nothing new here), and only 2 are genuinely new gaps worth naming.

The two real gaps

1. Cable-crossing disambiguation

JointJS's own team states the actual blocker plainly: smooth (curved) router links can't be intersection-tested for a jumpover-style arc/gap. PROJECT - pyblocks.md already worked through this in the same words — "hops and gaps are structurally incompatible with bezier edges" — and reached the right conclusion: decide the routing default first, then crossing marks. SystemSketch's default is still curved, so this stays blocked on that decision, exactly as already flagged. Not new information — confirmation the blocker is real, and that JointJS doesn't solve it for free either (it just doesn't offer the combination at all).

2. A generalized highlight primitive

JointJS's highlighters.add(cellView, selector, id, opts) is a small, uniform, non-destructive way to draw a stroke/mask/opacity/class highlight on any cell without touching its persisted style, keyed by id so it can be removed cleanly. SystemSketch does the same job today, but as bespoke logic behind each shape's own getCustomDisplayValues override seam rather than one shared primitive. Real, small, and low-risk to generalize once a third or fourth consumer of "temporarily highlight this shape" shows up — not worth doing speculatively for one.

License, and why it decides half the table

JointJS core is MPL-2.0 (LICENSE in clientio/joint), single-licensed, not dual. JointJS+ is a separate paid package (@joint/plus) carrying undo/redo, box selection, snaplines, halo, and the stencil palette — none of that ships in the free tier. One honest caveat on the "SystemSketch gets it for free" framing: tldraw's own SDK license changed in 2025 (v4+ needs a paid license for production use), so it's really "bundled into a cost already priced in elsewhere," not zero-cost in absolute terms — still strictly better than paying JointJS+ on top of a canvas-engine license.
